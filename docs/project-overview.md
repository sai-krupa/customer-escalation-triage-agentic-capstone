# Project Overview

## Customer Escalation Triage

This project demonstrates a hybrid AI-powered workflow for customer escalation triage.

The workflow combines Zapier automation, AI agents, Python-based processing, structured logging, rule-based routing recommendations, and human-in-the-loop review.

## Problem

Customer escalations traditionally require manual classification, prioritization, routing, tracking, and response preparation.

The goal of this project was to reduce repetitive analyst work while maintaining human oversight and improving traceability.

## Objectives

- Automate escalation classification
- Provide consistent routing recommendations
- Reduce manual analyst effort
- Reduce escalation processing time
- Improve auditability
- Maintain human review for appropriate decisions
- Measure workflow performance
- Establish regression testing
- Demonstrate measurable business value

## Business Impact

Processing time:

Approximately 15 minutes → less than 5 minutes per escalation

Improvement:

Approximately 67% faster

Analyst effort:

Approximately 25 hours/week → approximately 10 hours/week

Reduction:

Approximately 60%

Estimated analyst capacity reclaimed:

Approximately 15 hours/week

Estimated annual capacity:

Approximately 780 hours/year
